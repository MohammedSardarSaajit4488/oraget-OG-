# Oraget

![Oraget Logo](https://via.placeholder.com/150 "Oraget Logo")

**Oraget** is a budget management and recommendation app designed to help users set and manage their budget limits and receive personalized recommendations for dining out, shopping, and other activities. With features like meal timing, water consumption tracking, recipe management, and AI-powered chatbot assistance, Oraget aims to provide a comprehensive solution for personal finance management.

## Features

- **User Authentication**: Sign up, login, and manage user profiles.
- **Budget Setup**: Define and manage budget limits for different categories.
- **Expense Tracking**: Log and categorize expenses.
- **Recommendations**: Personalized suggestions for dining out, shopping, and activities.
- **Notifications**: Alerts and reminders.
- **Analytics and Insights**: Spending trends and budget adherence reports.
- **Meal Timing and Water Consumption**: Set and track meal times and water intake.
- **Recipe Management**: Input and manage recipe details (calories, protein, etc.).
- **AI Chatbot**: Interact with an AI chatbot for personalized recommendations and assistance.

## Getting Started

### Prerequisites

- **Android Studio**: Download and install Android Studio from the [official website](https://developer.android.com/studio).
- **Firebase Account**: Create a Firebase account and set up a new project in the [Firebase Console](https://console.firebase.google.com/).
- **Third-party APIs**: Obtain API keys for third-party services like Yelp API, RetailMeNot API, and a chatbot API (e.g., Dialogflow, OpenAI).

### Installation

1. **Clone the Repository**:
   ```bash
   git clone https://github.com/yourusername/oraget.git
   cd oraget
### Configure Firebase :

Download the google-services.json file from your Firebase project and place it in the app/ directory.
Update the build.gradle files with your Firebase configuration.

### Add Third-party API Keys :
Open app/src/main/res/values/strings.xml and add your API keys:

1.<string name="yelp_api_key">YOUR_YELP_API_KEY</string>.

2.<string name="retailmenot_api_key">YOUR_RETAILMENOT_API_KEY</string>.

3.<string name="chatbot_api_key">YOUR_CHATBOT_API_KEY</string>.

### Build and Run the App :
Open the project in Android Studio.
Connect an Android device or start an emulator.
Click the "Run" button to build and deploy the app.

### Usage
Sign Up/Login :
Open the app and sign up or log in using your email and password.

Set Budget Limits :
Navigate to the "Budget Setup" screen and define monthly budget limits for different categories.

Log Expenses :
Use the "Expense Log" screen to manually log expenses with details (amount, category, date, description).

Receive Recommendations :
The "Recommendation" screen provides personalized suggestions for dining out, shopping, and activities based on your budget and preferences.
Track Meal Timings and Water Consumption :
Use the "Meal Timing" and "Water Consumption" screens to set and track your meal times and water intake.

Manage Recipes :
The "Recipe Management" screen allows you to input and manage recipe details (calories, protein, etc.).

Interact with AI Chatbot :
Use the "Chatbot" screen to ask the AI for personalized recommendations and assistance.
